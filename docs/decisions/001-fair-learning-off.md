# 001: Learning off is a fair mode with its own skill input

Context: learning off won every fight (no meter, near-top damage), so it read as the easy mode and taught that answering is a penalty.
Decision: one damage formula for both modes (base x skill bonus, 1.0 to 1.4); the foe meter runs in both; learning off uses a timing ring (Growing) or a cheer tap (Early, or timing switched off) that earns the same bonus range. Same XP in both modes.
Consequences: a wrong answer now does the base (16) instead of 14, which nudges learning-on win rates up slightly; FAST special retuned to 0.68. Learning off can now be lost, which the youngest may notice at giants (cheer giants about 87%, close to a child answering half right). Revisit cheer pacing after a playtest.
